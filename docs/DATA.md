# 입력 데이터 계약

모든 CSV는 UTF-8이고 헤더가 필요합니다. 타임스탬프는 `2024-02-01T14:30:00Z`처럼 시간대가 명시된 ISO 8601입니다. 코드가 날짜만 보고 미국 DST·한국 휴장일을 추정하지 않습니다.

## sessions.csv

```csv
market,open_time,close_time
US,2024-02-01T14:30:00Z,2024-02-01T21:00:00Z
```

공식 거래소 일정의 정규 세션을 공급하세요. 조기 폐장·휴장·DST도 이 파일에 반영합니다. 이 버전은 시장 간 세션 또는 판단 준비 구간이 겹치지 않는 일봉 실험을 지원합니다. 겹치는 시장을 비교하려면 동기화된 다중 시장 엔진으로 확장해야 하며, 현재 검증기는 이를 거부합니다. 자료의 실제 거래소·시간대·세션을 사용하세요.

## bars.csv

```csv
market,symbol,name,sector,open_time,close_time,available_at,open,high,low,close,volume,tradable_at_open
US,EXAMPLE,Example Company,Technology,2024-02-01T14:30:00Z,2024-02-01T21:00:00Z,2024-02-01T21:00:00Z,100.00,103.00,99.00,102.00,1000000,true
```

- `open/high/low/close`는 **실제 통화 가격**입니다. USD `100.00`은 100달러이며 입력 후 10,000센트로 정규화됩니다. KRW는 원 단위 정수입니다.
- `available_at`은 해당 완료 봉을 실제 이용할 수 있었던 시각입니다. 종가보다 빠를 수 없습니다. 미래 봉의 시가·종가·고가·저가·거래량은 판단 패킷에 넣지 않습니다.
- `volume`은 주식 수량이며 거래대금이 아닙니다. 참여 한도는 이전 완료 봉 거래량의 중앙값 × `liquidity_participation`입니다.
- `tradable_at_open=false`는 해당 시점 거래정지 등으로 시가 체결이 불가능했음을 나타냅니다. 미래의 하루 총거래량으로 개장 시 체결 가능성을 추측하지 않습니다.
- 고정 종목군의 모든 종목은 전체 평가 세션에 봉이 필요합니다. 누락·중복·비정상 OHLC·부족한 준비 기간은 과금 전 검증에서 중단됩니다.
- `name`·`sector`는 표시와 판단에 사용됩니다. 실행 중 동일 종목의 메타데이터가 바뀌면 실패합니다. 당시 업종 분류를 사용하지 않으면 또 다른 편향이 생길 수 있습니다.
- 조정주가와 원주가를 섞지 마세요. 제공자의 수정 이력·주가 조정 정책·사용 권한은 사용자가 확인해야 합니다.

## 기간

`start <= session.open < end`인 세션을 평가합니다. `end`는 배타적 경계이고, 포함된 세션의 마감 자료 공개 시각까지 포괄해야 합니다. 시작 이전 최소 `warmup_bars`개 봉을 더 공급하세요. 기본은 20개입니다.

선택한 준비 기간 이전의 기업행사도 준비 봉 가격을 왜곡할 수 있습니다. 실제 데이터에 기업행사가 있었다면 그냥 `no_actions_confirmed`로 선언하지 마세요.

## 기업행사

```csv
market,symbol,kind,effective_at,published_at,value
US,EXAMPLE,cash_dividend,2024-02-10T14:00:00Z,2024-01-15T12:00:00Z,0.25
```

현재 지원하는 `cash_dividend`는 **effective_at에 보유한 주식당 실제 순현금 지급액**입니다. 해당 시각의 보유 수량 × `value`를 현금에 더합니다. 배당락일 보유자와 지급일 보유자가 다른 일반 배당을 자동 복원하는 엔진이 아닙니다. 두 시점이 다른 데이터는 사전에 정확한 권리 기록을 갖춘 확장 엔진이 필요합니다. 세금 차감 여부도 `value`에 명시적으로 반영하세요.

`split` 행은 감지와 중단을 위해 인식하지만 현재 지원하지 않습니다. 원장을 잘못 계산하는 것보다 실행을 거부합니다. 배당/분할이 없는 검증 구간을 선택하거나 기업행사 엔진을 구현·테스트한 뒤 새로운 실험으로 시작하세요.

## 실행 가능한 완전한 입력 예제

```sh
python -m namuh_lab run --config examples/demo/config.json --out runs/from-csv
```

`examples/demo/`의 30개 날짜·2개 시장·8개 종목은 프로그램이 만든 **합성 데이터**입니다. 실제 거래소 휴장일·가격이 아니며 사용법과 테스트용입니다. 이 파일의 헤더와 시간대 표현을 참고해 사용 허가된 실제 데이터를 변환하세요.
