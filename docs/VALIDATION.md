# 검증 범위

기본 테스트는 합성 데이터와 오프라인 가짜 공급자를 사용합니다. 실제 증권사나 OpenRouter 계정은 필요하지 않습니다.

초기 공개판 작성 환경에서는 Windows / Python 3.13에서 29개 테스트, 별도 가상환경 wheel 빌드·설치·오프라인 데모 실행, 데스크톱·모바일 HTML 보고서 동작을 확인했습니다. 다른 환경의 결과는 CI에서 별도로 확인해야 합니다.

검증하는 주요 불변 조건:

- 당일 시가·종가·거래량을 바꿔도 그 세션의 판단 스냅샷은 달라지지 않습니다.
- 6개 참가자의 공개 시장 스냅샷과 해시가 동일합니다.
- 초 단위 시각을 반환하는 첫 종목도 마감 다음 초 장벽 이후 정상 통과합니다.
- 키 잔액이 부족하면 모델 호출 전 중단하고, 호출 도중 공통 장애가 나면 아무도 체결되지 않습니다.
- 모델 하나의 JSON 오류와 공통 인프라 장애를 구분합니다.
- 시가 갭으로 예산을 넘는 묶음은 원장에 일부만 반영되지 않습니다.
- 같은 출력 폴더의 재실행·재개가 중복 거래를 만들지 않습니다.
- 설정·코드·데이터가 달라지면 기존 실행을 재개하지 않습니다.
- 중단된 유료 요청은 자동 재호출하지 않습니다.
- HTML과 CSV에 외부 출력이 실행 코드·수식으로 들어가지 않게 처리합니다.
- 소스 공개 검사에는 런타임 DB·키·개인 경로·개인 메일·개인 서버 주소를 포함하지 않습니다.

## 아직 검증하지 않은 것

- 사용자가 선택한 실제 모델 6개가 지금 해당 공급자에서 호출 가능한지
- 모델별 문맥 길이·토큰화·추론 비용 추정의 정확한 동등성
- 실제 공급자의 네트워크 지연·시각 오차·rate limit·일별 키 한도
- 실제 증권 주문·호가 대기열·결제일·배당 권리·분할·상장폐지 처리
- GitHub Actions의 9개 OS/Python 조합 실제 실행 결과: 저장소를 업로드한 뒤 CI 결과로 확인

따라서 기본 테스트 통과는 과거 데이터 실험 엔진의 특정 불변 조건에 대한 증거이며, 무중단 서비스나 수익을 보장하는 인증이 아닙니다.
